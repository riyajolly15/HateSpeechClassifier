# Hate Speech Detection
This is a Streamlit-based web application that detects hateful speech
using TF-IDF and Logistic Regression.

## Tech Stack
- Python
- Scikit-learn
- Streamlit

## How it works
- User enters text
- Text is vectorized using TF-IDF
- Logistic Regression predicts hate / non-hate
- Result shown with confidence score
